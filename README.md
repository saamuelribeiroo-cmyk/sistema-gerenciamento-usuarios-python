Sistema de Gerenciamento de Usuários

Sistema desenvolvido em Python para gerenciamento de usuários através do terminal. O projeto permite cadastrar, pesquisar,
excluir, listar e salvar informações de usuários em um arquivo de texto.

Funcionalidades
Inserção de novos usuários
Pesquisa de usuários pelo login
Exclusão de usuários
Listagem de usuários cadastrados
Salvamento dos dados em arquivo .txt
Menu interativo pelo terminal

Tecnologias utilizadas
Python
Manipulação de dicionários
Entrada e saída de dados
Manipulação de arquivos com open()

📌 Objetivo
Projeto desenvolvido para praticar conceitos fundamentais de Python, como funções, estruturas de dados,
condicionais, laços de repetição e manipulação de arquivos.
